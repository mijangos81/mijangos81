### Luis Mijangos

Population geneticist at [Diversity Arrays Technology (DArT)](https://www.diversityarrays.com) and lead developer of [dartR and the dartRverse](https://github.com/green-striped-gecko/dartRverse), open-source R packages for SNP data analysis used in more than 1,600 scientific publications. The dartR team won the 2025 ARDC Eureka Prize for Excellence in Research Software.

**What I work on**

- **Conservation genomics:** effective population size, relatedness and genetic management of threatened species, such as the woylie, platypus and Gilbert's potoroo.
- **Breeding analytics:** QTL mapping, GWAS, varietal identification and a SNP panel for dog breeds.
- **AI tools for population genetics:** Claude Code skills for the dartR team ([dartrverse-skills](https://github.com/mijangos81/dartrverse-skills)), an MCP server that lets agents run population-genetic analyses ([dartr-tools](https://github.com/mijangos81/dartr-tools)), and simulations with a known answer to test what an estimator can and cannot tell you.

**Teaching**

- [Getting started with dartRverse](https://doi.org/10.26191/xrkg-6996), an open-access textbook (2026).
- [Population Genomics in R](https://github.com/mijangos81/PopGenR), workshop material.
